# MicControl

System-wide microphone mute/unmute with hotkeys, an always-on-top overlay, sounds and a tray icon. Its own app, inspired by MicSwitch by Xab3r. .NET 10, Avalonia 12.1, C# latest; solution `Sources/MicControl.slnx`. Windows 10 (2004+) and 11 only for now; Linux (KDE Plasma 6/Wayland, CachyOS/AUR) and macOS come later.

## Commands (from `Sources/`)
- Build: `dotnet build MicControl.slnx` (warnings are errors; strict analyzers).
- Test: `dotnet test --project MicControl.Tests` (Microsoft Testing Platform; the old `dotnet test <proj>` form fails). Tests run on Windows and Linux.
- Run (Windows): `dotnet run --project MicControl`, elevated.
- After any package change: `dotnet run tools/GenerateThirdPartyNotices.cs` from the repo root (CI checks it).

## Hard rules (developer's)
- **Name**: "MicControl" everywhere; never "NG" or "Next Generation". "MicSwitch" appears only for compatibility (settings import, old autostart entries) and the credit "Inspired by MicSwitch by Xab3r".
- **License GPL-3.0-or-later**: everything bundled must be GPL-3-compatible (MIT, BSD, Apache-2.0, zlib, public domain); never MS-PL, CC-BY-NC, proprietary or non-commercial-only libraries (BASS, CSCore). No NuGet crypto packages.
- **Privacy**: the app's only network access is the GitHub release check and update download. Never add analytics, crash reporting or other phone-home. Opt build tools out of telemetry. Never use Dependabot update PRs or assign alerts to Copilot; fix alerts on a `fix/` branch.
- **Packaging** is native per OS, never Flatpak/Snap/AppImage. **No installer framework** (no Velopack, Inno Setup, WiX, MSIX): the app installs itself so the installer looks like the app.
- **Updates** install only if `SHA512SUMS.sig` is a valid signature by a key in `ReleaseKeys.Trusted` and the download matches the signed SHA-512; GitHub's digest doesn't count, and a mismatch deletes the file and never falls back.
- **Signing keys** are Ed25519 via `ssh-keygen`/`tools/Signing.ps1`; passphrases are generated, never chosen. The release key never leaves the developer's PC and is never in CI.
- **Mute is safe**: push-to-talk never stays live, no microphone looks muted, and mute never depends on a future audio engine.
- **Shutdown**: a session end always exits cleanly and never hides to the tray; hidden windows refuse external closes (the tray "zombie" bug).
- **Defaults**: Push-to-talk, Muted at startup, exclusive hotkeys off, close to the tray on; a MicSwitch import never brings its mode or startup state. Users never see "App mode"/"Tray mode"/"Window mode". Optional features are "Custom X" switches in About → Advanced that add a page named "X".
- **Assets** (icons, cue sounds, icon font) are generated by `tools/`, never hand-edited; notification sounds must be CC0/public domain.
- **Settings** (`%APPDATA%\MicControl\settings.json`) stay plain JSON and compatible with MicSwitch 1.x hotkey strings; a bad file never crashes the app or gets saved over; bump `AppSettings.CurrentVersion` only with a migration.
- **Code**: `MicControl.Core` has no UI or OS dependencies, the UI talks to the OS only through `MicControl.Platform` interfaces, and Windows code lives in `MicControl.Windows`. A new platform capability gets an interface, a Windows implementation, a test fake and a `PlatformCapabilities` flag if needed. Logging uses `[LoggerMessage]` only. Add tests for behavior changes.
- **Roadmap order**: 1.0.1 → 1.x features → audio engine → speech enhancement → per-app capture → Linux → output buses. Never bundle a virtual audio driver; never integrate with Teams or other Microsoft proprietary software.
- **Tools**: the developer uses Visual Studio Enterprise and Sublime Text only; never suggest VS Code or JetBrains.

## Git (developer's rules; details in `git-workflow`)
- Branches: `master` (releases, pushed only from the developer's PC, no PRs into it), `dev`, and task branches `feature/<name>` or `fix/<name>` off `dev`. Never `claude/...` or other generated names.
- One PR per task into `dev`, opened only when the work is complete. Merge by fast-forwarding `dev` to the PR commit once CI passes, then delete the branch with the `Maintenance` workflow.
- Author and committer are always `Chaotic Holon <ChaoticHolon@users.noreply.github.com>`, with no Co-Authored-By or other Claude/AI lines.
- History on `dev`/`master` is condensed to one commit per day or per task, no merge commits. The rulesets refuse force-pushes from the cloud, so condensing (or anything needing a bypass) goes to the developer as one PowerShell block. Rewrite only with identical files and `--force-with-lease`, never at or below a release tag; release tags are never moved or deleted.
- Releases are tagged `vMAJOR.MINOR.PATCH` on `master` (SemVer; versioning restarted at 1.0.0); `<Version>` is in `Sources/Directory.Build.props`.
- Keep `.gitignore` current: `git ls-files -ci --exclude-standard` must list nothing.
